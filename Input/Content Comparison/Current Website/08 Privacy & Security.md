# 8. Privacy & Security — CURRENT

- **Eyebrow:** PRIVACY BY DEFAULT
- **Title:** Your workflow stays yours.
- **Description:** Everything stays in ~/.nexpath/. Your repository is never uploaded or indexed.

## Features (3 cards)

1. **Automatic secret redaction**
   API keys, tokens, and PEM blocks are stripped before a prompt is stored.

2. **Local prompt control**
   Delete, prune, or clear stored prompts with one command.

3. **Targeted guidance only**
   No filler. If there is nothing useful to add, NexPath CLI stays out of the way.

## "WHAT NEXPATH IS NOT" strip
- Not a coding agent
- Not a linter or CI
- Runs once, on the prompt, before the agent writes code
