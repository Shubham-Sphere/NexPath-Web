# 4. Enterprise Privacy & Internal Device Network — CURRENT

- **Eyebrow:** ENTERPRISE CAPABILITIES
- **Title:** ENTERPRISE PRIVACY & INTERNAL DEVICE NETWORK
- **Heading:** Your code. Your infrastructure. Your control.
- **Intro:** AI-assisted development introduces an important question: where does your project information go when a coding agent processes it?
- **Intro 2:** NexPath brings privacy-focused local AI workflows to developers who need greater control over how their code and project context are processed.

## Features (5 items)

1. **Use your internal device network**
   Connect supported internal devices and use compatible local models running on your own hardware, including GPUs where supported.

2. **Activate Data Privacy Mode**
   When Data Privacy Mode is enabled and correctly configured, model inference in the protected workflow is restricted to designated internal models rather than external model APIs. Your code and project information for that inference remain within the configured internal device network.
   If a task needs a capability that the configured internal models cannot provide, NexPath brings you into the decision. Data Privacy Mode does not silently fall back to an external model API.

3. **Work with different coding agents and keep context aligned**
   Use different coding agents for different tasks. Context Engineering helps keep important project context available as you switch, so you do not have to rebuild the same project understanding each time.
   NexPath can also bring you into the loop when a task may be handled by a more suitable or more cost-effective agent. Smaller tasks that do not need a premium model may be handled by an appropriate lower-cost or local option, helping reduce unnecessary subscription or token costs without lowering the quality bar for the work.

4. **Put your internal GPUs to work**
   You do not need to manually choose a local model for every task. When Data Privacy Mode is on, suitable work is routed to compatible models on your configured internal device network. Model selection is automatic within that protected setup; external model APIs are not used. Suitability and performance depend on the model, hardware, and task.

5. **Support mature software engineering**
   Enterprise capabilities extend the open-source foundation with evidence-based software engineering workflows that support maintainability and more deliberate verification.

- **Supporting line:** Enterprise privacy capabilities, with the focus still on better software engineering and developer control.
