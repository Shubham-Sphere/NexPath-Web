# 3. Context Engineering & Project Memory (Plan)

- **Eyebrow:** INTELLIGENT CONTEXT

## Heading
Your project has a memory. Your coding agent should have the right context, too.

## Body
Important project decisions do not always belong to the current conversation. Architecture choices, earlier implementation details, established conventions, and lessons learned can remain relevant long after the original discussion.

NexPath's Context Engineering capabilities are designed to help preserve that knowledge and bring relevant context back when it matters.

## Subsections

1. **Remember beyond the current session**
   Important project context can remain useful even when it was recorded weeks or months earlier.

2. **Learn project patterns**
   Pattern recognition helps identify recurring information and relationships within a project's accumulated context.

3. **Retrieve what matters for the task**
   Instead of relying exclusively on whatever happens to be present in the current conversation, NexPath aims to make relevant historical context available when a task calls for it.

4. **Maintain continuity across coding agents**
   When you move between coding agents, relevant project knowledge can help keep their understanding aligned with the decisions and conventions established earlier.

- **Supporting line:** Not just longer memory. More useful context at the right time.
- **Note:** Context Engineering is part of NexPath's open-source foundation.
