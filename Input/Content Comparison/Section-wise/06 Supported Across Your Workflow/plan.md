# 6. Supported Across Your Workflow — UPDATED (Plan)

- **Eyebrow:** BUILT AROUND YOUR DEVELOPMENT WORKFLOW

## Heading
Your tools. Your workflow. One familiar way to work.

## Body
NexPath is designed to complement the tools developers already use rather than require an entirely different development process.

## Items (4)

1. **NexPath Desktop App**
   The Desktop App is the current home of NexPath's premium capabilities, including Data Privacy Mode, the internal device network, and supported background workflows.

2. **Browser Extension**
   Use the browser extension for its supported NexPath functionality within compatible browser-based workflows. Premium capabilities are not currently available through the Browser Extension.

3. **VS Code Extension**
   Bring supported NexPath functionality into compatible editor workflows. Premium capabilities are not currently available through the VS Code Extension.

4. **NexPath CLI**
   Access supported command-line functionality from your terminal. Premium capabilities are not currently available through the CLI.

- **Supporting line:** Premium capabilities are currently available through the Desktop App only.
