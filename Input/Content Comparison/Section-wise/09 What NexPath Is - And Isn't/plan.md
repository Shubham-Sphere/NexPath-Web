# 9. What NexPath Is — And Isn't (Plan)

- **Eyebrow:** A DIFFERENT LAYER IN YOUR WORKFLOW

## Heading
NexPath works with your coding agents, not instead of them.

## Body
NexPath is designed to improve the way you work with AI coding agents while keeping developers involved in important decisions.
It is not intended to replace every coding agent with a new, all-in-one agent.

## Items

1. **NexPath is a human-in-the-loop layer**
   It helps improve prompts, maintain relevant project context, support suitable background workflows, and involve developers when their input matters.

2. **NexPath is not another coding agent**
   You can continue using the coding agents that suit your tasks and workflow.

3. **NexPath is not a replacement for engineering judgment**
   Automation can reduce repetitive work, but developers remain responsible for important technical decisions, appropriate verification, and the quality of the resulting software.

4. **NexPath is not simply a prompt wrapper**
   Its broader direction includes context engineering, privacy-focused local workflows, and ways to make interactions between developers and coding agents more effective.

- **Supporting line:** Your coding agents do the work. NexPath helps make the workflow more effective, controlled, and maintainable.
