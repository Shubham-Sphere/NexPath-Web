# 2. How It Works — Prompt Enhancement (Plan)

- **Eyebrow:** PROMPT ENHANCEMENT

## Heading
Better guidance before your coding agent starts.

## Body
A coding agent is only as effective as the instructions and context it receives. NexPath strengthens your prompts with relevant software engineering guidance, helping your agent work toward clearer requirements, better implementation decisions, and more maintainable code.

## Steps

1. **Understand your intent**
   NexPath considers your request and relevant session context to understand what you want to accomplish without unnecessarily changing your original intent.

2. **Structure the task**
   It organizes your requirements into a clearer, more actionable prompt that helps your coding agent understand the intended scope and expected outcome.

3. **Apply software engineering guidance**
   Relevant guidance can help your agent account for maintainability, verification, safety, and other engineering considerations appropriate to the task.

4. **Keep control when it matters**
   Prompt enhancement can run automatically, with a six-second cancellation window so you can stop the automatic enhancement when necessary.
   NexPath aims to reduce unnecessary interruptions while keeping you in control of how your coding workflow operates.

- **Supporting line:** Less time refining instructions. More attention on the engineering decisions that matter.
