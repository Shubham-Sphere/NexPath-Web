# 11. FAQ (Plan)

Title: Frequently Asked Questions

1. **Is NexPath another AI coding agent?**
   No. NexPath is designed to work alongside coding agents. It improves the surrounding workflow through prompt enhancement, context engineering, and supported human-in-the-loop capabilities.

2. **What does NexPath's human-in-the-loop approach mean?**
   It means keeping developers involved where their judgment, decisions, or intervention matter, while reducing unnecessary manual work through supported automation.

3. **What is Prompt Enhancement?**
   Prompt Enhancement improves the clarity, structure, and relevant engineering guidance of a developer's request before the coding agent acts.

4. **Does NexPath automatically enhance prompts?**
   Supported automatic prompt enhancement can run without requiring the developer to approve every enhancement in advance. A six-second cancellation window allows the user to stop the automatic enhancement when necessary.

5. **What is Context Engineering?**
   Context Engineering helps make relevant project information available for the task at hand. NexPath's approach includes long-term context and pattern recognition intended to help retrieve useful information beyond the current conversation.

6. **Can I switch between different coding agents?**
   NexPath's multi-agent workflow direction supports working with different coding agents according to the task, while helping maintain relevant project context across transitions.
   The exact integrations and switching capabilities depend on the supported workflow.

7. **What does Data Privacy Mode do?**
   When correctly configured, Data Privacy Mode restricts supported model inference to designated internal models rather than external model APIs. Its exact guarantees depend on the implementation and the workflow being used.

8. **Can I use my own GPU?**
   Compatible local models can use supported GPU hardware. Performance and suitability depend on the GPU, available memory, model requirements, and the task.

9. **Can NexPath run testing and verification in the background?**
   Supported background workflows can help execute suitable tasks without requiring continuous attention. Developer input may still be needed when clarification, approval, or engineering judgment is required.

10. **Will background mode reduce my costs?**
    It can help reduce token expenditure when suitable tasks are handled by less expensive models or agents. Actual savings depend on the task, the models used, the pricing structure, and the amount of work delegated.

11. **Where are premium features available?**
    Premium features are currently available through the NexPath Desktop App. The Browser Extension, VS Code Extension, and CLI provide their respective supported functionality but should not be assumed to include the same premium capabilities.

12. **Is NexPath open source?**
    NexPath has an open-source foundation, with its available open-source functionality documented in the project repository. Additional Enterprise capabilities extend the experience for more demanding workflows.

13. **Does NexPath replace software testing or developer judgment?**
    No. NexPath can support verification workflows and help improve engineering guidance, but it does not eliminate the need for appropriate testing, review, and developer judgment.
